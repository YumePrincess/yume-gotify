# Security policy

Yume Gotify is provided as-is. It has not received an independent security
audit or certification, and the maintainers make no guarantee that a particular
deployment is suitable for production.

Before deploying, review the code and Wrangler settings, use unique strong
secrets, restrict administrator access, and keep production credentials out of
source control.

Report suspected vulnerabilities through GitHub's private vulnerability
reporting or a private Security Advisory for this repository. Do not include
live credentials in public issues. There is no guaranteed response time.
